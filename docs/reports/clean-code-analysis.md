## lib/list-actions.ts

### [HIGH] `addListItem` exceeds recommended length — lines 56–82

`addListItem()` performs form parsing, month/year normalization, schema validation, user lookup, and service dispatch — five concerns in 27 lines.

**Fix:** Extract form data parsing into a helper:

```typescript
function normalizeMonthYear(rawMonth: number, rawYear: number, fallback: Date) {
  const month = Number.isInteger(rawMonth) && rawMonth >= 1 && rawMonth <= 12
    ? rawMonth
    : fallback.getMonth() + 1;
  const year = Number.isInteger(rawYear) && rawYear >= 2000 && rawYear <= 2100
    ? rawYear
    : fallback.getFullYear();
  return { month, year };
}
```

## lib/list-service.ts

### [HIGH] Silent `.catch(() => {})` swallows real errors — line 19

Only duplicate-key errors (`P2002`) should be silently ignored. All other failures are hidden.

```typescript
// Before
await prisma.listMember.create({ data: { listId, userId } }).catch(() => {});

// After
try {
  await prisma.listMember.create({ data: { listId, userId } });
} catch (err) {
  if (!(err instanceof PrismaClientKnownRequestError && err.code === "P2002")) {
    throw err;
  }
}
```

### [HIGH] `serviceGetItemPrices` is 78 lines with 5+ concerns — lines 21–98

Authentication, cache retrieval, freshness check, adapter dispatch, cache upsert, and result assembly should be separate functions.

## Refactoring Priorities

1. **Extract shared constants** — `lib/constants/time.ts`, `lib/constants/errors.ts` (unblocks many other items)
2. **Fix silent error swallow** — `list-service.ts` `.catch(() => {})` (correctness risk)
3. **Extract `normalizeMonthYear`** — eliminates page/action duplication (DRY)
4. **Extract `priceResultToRecord`** — removes 6-field duplication in price upsert (DRY)
5. **Break up `serviceGetItemPrices`** — biggest SRP violation (testability)
6. **Add `useMemo` to `PriceComparison`** — unnecessary computation on every render (perf)
7. **Consolidate Zod schemas** — `emailField`, shared validators (DRY)
